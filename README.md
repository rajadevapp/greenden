# 🌿 Greenden Website

A responsive **Greenden website** developed using **HTML and Tailwind CSS**.  
The website focuses on a clean, modern, and nature-inspired design for a plant and gardening business.

## 🌱 About the Project

Greenden is a responsive plant website created to practice and demonstrate modern web design using **HTML** and **Tailwind CSS**.

The website includes multiple pages with a simple and user-friendly interface, responsive layouts, product sections, client information, and a contact form.

## ✨ Features

- 🌿 Responsive design for different screen sizes
- 🏠 Home page
- 🪴 Products page
- 👥 Our Clients page
- 📞 Contact page
- 🎨 Modern and clean UI
- 📱 Mobile, tablet, and desktop responsive layouts
- ⚡ Tailwind CSS utility classes
- 🌱 Nature-inspired design

## 📄 Pages

### 🏠 Home
The home page introduces the Greenden website with:
- Hero section
- Plant-related content
- Featured products
- Services/features
- Call-to-action sections

### 🪴 Products
Displays the available plants and products with:
- Product images
- Product names
- Product information
- Responsive product layout

### 👥 Our Clients
A dedicated section showcasing clients and customer-related content with a clean responsive layout.

### 📞 Contact
A contact page where visitors can:
- Enter their name
- Enter their email
- Submit their message
- Find contact-related information

## 🛠️ Technologies Used

- **HTML5**
- **Tailwind CSS**
- **SVG Icons**
- **Responsive Web Design**

## 📱 Responsive Design

The website is designed to work across different screen sizes:

- 📱 Mobile
- 📱 Tablet
- 💻 Laptop
- 🖥️ Desktop

Tailwind CSS responsive utilities such as `sm:`, `md:`, and `lg:` are used to create responsive layouts.

## 🎨 Design

The design uses a natural color palette inspired by plants and greenery, with clean spacing, typography, cards, buttons, and responsive sections.
